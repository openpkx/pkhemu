# Screenshots

Renders screens with the test fakes in Chromium, without Tauri, and saves each at 390px and 1280px wide, in dark and light, with a touch pointer and a mouse, to `out/`, which git ignores. On touch it reports any button or menu row under 44px.

From `app/`:

```sh
npx playwright install chromium   # once
npm run screenshots               # every screen
npm run screenshots -- game-page  # only the screens whose names start so
```

Files are named `<screen>-<theme>-<width>-<pointer>.png`.

The library has box art for FireRed and last screens for Emerald and Platinum, drawn on a canvas. Platinum's is 256×384, a blue top screen over a red bottom one, so its tile and `game-page-nds-art` show the crop to the top screen. PKSM's is the 3DS's 400×480, a green top screen over a red bottom one with black beside it. `library-3ds` turns on the 3DS experiment and continues PKSM with Platinum beside it in Recently played, and `game-page-3ds-art` shows its crop. `library` continues Emerald from its resume point, `library-no-resume` has no resume point, `library-cloud` continues cloud-only Sapphire, and `library-unplayed` has nothing played. `library-empty` is the empty library with Open folder, `library-empty-android` without it, and `library-import-menu` has the + menu open. `import-which-game` and `import-replace` show the import's two questions over the library. The `import-folder-` screens walk through importing a folder: `where`, `where-emulator` for another emulator's folder with Android's hint, `where-emulator-ios`, `where-emulator-ipad` and `where-emulator-mac`, `scanning`, `summary` from the library, `summary-onboarding` from the welcome screen, `empty` when a folder has no games, `new-folder`, `copying` and `conflicts`. `welcome` is the welcome screen with no games folder, and `welcome-folder` the screen "I'm new to emulators" opens. `welcome-previous` is the screen "I've used pkhemu before" opens, and `welcome-previous-warning` shows it after picking a folder with no system folders. The `-mac` versions show the Mac's wording, the `-ios` versions the iPhone's and the `-ipad` versions the iPad's. The game page has a screen per system, `game-page-gba` for example, one with a last screen, `game-page-gba-art`, and `game-page-gba-menu` with the ⋯ menu open and a "Patched from" note. `overlays` shows a toast, the opponent pill and a sync badge in each state, `overlays-dialog` an alert dialog over the library, `transfer` the transfer list with a game in each route state, `box-art-sheet` the box art sheet over the library, `editor-stadium` the editor's home for a Stadium save, `editor-teams` its Teams page, `editor-mystery-gift` the Mystery Gift page of a Platinum save, `editor-mystery-gift-preview` an event's preview and `editor-mystery-gift-review` its Review card. Gallery images from thumbnails.libretro.com are drawn placeholders.

`playing-gb`, `playing-gbc`, `playing-gba`, `playing-nds`, `playing-n64` and `playing-3ds` run the game screen on a checkerboard frame with touch controls and Fast-forward on. They're shot with a touch pointer only, in portrait at 390×844 and landscape at 844×390, at 3×, named `<screen>-<theme>-<portrait|landscape>-touch.png`. `playing-gb`, `playing-nds` and `playing-3ds` also get portrait shots of the handheld display with the tilt forced to a shift in dp, `-shift+5+5` and `-shift-5-5`, and with the glass on, `-glass` and `-glass-shift+5+5`. `screenshots/tilt.ts` stands in for the tilt to hold that shift. Every playing screen also gets portrait shots in Frosted (`-frosted`), in a light skin (`-skin-classic-grey`, `-skin-glacier`, `-skin-polar-white` or `-skin-gold`), and in one free skin per system in both looks (`-skin-<id>` and `-skin-<id>-frosted`). `&skin=<id>` picks any skin and `&look=frosted` the look. Each playing screen also gets a `-paused` shot in both orientations with the pause menu open over its free skin.

`settings-skins` turns Touch controls on and opens Settings › Skins. `skin-picker-gb` to `skin-picker-3ds` show the skin picker over the same checkerboard, in portrait and landscape at 3×, with portrait shots of a black preview (`-empty`), Frosted (`-frosted`) and a swipe held halfway (`-swiping`). `&hinted` stops the hint, which the shots pass so it doesn't catch them mid-way.

To add a screen, add an entry to `screens` in `main.tsx` and its name to `screens` in `capture.mjs`. Give it data through the fakes and hosts in `main.tsx`. `vitest.ts` stands in for vitest, since the fakes call `vi.fn`.

The Google Play screenshots have their own setup in `store/`. See `store/README.md`.
